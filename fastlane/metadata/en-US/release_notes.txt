Decaid is here: the official Decent Espresso app for the DE1 family and Bengle. Connect your machine, follow every shot live, pick a skin and start brewing.

Extension management security is now opt-in. Decaid 0.9.3 turns off the always-on protection that 0.9.2 applied to plugin and skin management, for new installs and upgrades, so Home Assistant, MCP clients, skins and other integrations work without API tokens again. While the new Settings > Security switch "Require authorization for extension management" is off, anyone who can reach the device on your network, or a plugin allowed to call the management API, can install, modify, approve and remove extensions, approve permission escalations and change extension settings. Turn it on for a shared device or a cafe, and restrict network access to the tablet; the cafe hardening guide is forthcoming (issue #1192). The switch covers extension management only, and API tokens are sent over plain HTTP on port 8080, so use a trusted network until HTTPS (#925) ships; optional full API authentication is tracked separately (#1135).
